# Verträge

Die JSON-Schemas beschreiben die äußere Dateiform. Die semantisch strengeren Prüfungen werden ohne Drittbibliotheken in `verify_presentmon.py` ausgeführt und getestet. JSON-Schema-Konformität allein ist keine Abnahme. QPC muss als Integer erhalten bleiben; Prozess-FILETIME wird zur Übertragungsrobustheit als Dezimalstring gespeichert. Die Aufnahmebewertungsvorlage ist absichtlich unausgefüllt und nicht als Testresultat zu interpretieren.
